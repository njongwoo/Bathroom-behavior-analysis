## I. Proposal

### 연구 동기

본 프로젝트에서는 가상의 화장실 환경을 구성하고, 인공지능을 활용해 소변기 선택 행동 패턴을 분석하고자 한다.

### 연구 목표
- 소변기별 이용 빈도 분석
- 혼잡도에 따른 선택 행동 비교
- AI 학습 기법을 이용한 행동 패턴 분석
